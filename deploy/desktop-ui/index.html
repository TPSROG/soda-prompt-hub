先连接本机 ComfyUI

启动你的 ComfyUI，确认浏览器可以打开它。默认地址是 http://127.0.0.1:8188；使用其他端口时，在设置里修改。

选择专用任务目录，例如 D:\PromptHub-Bridge\prompt-hub。只共享它的上级文件夹，不要共享整个磁盘、模型目录或个人资料。

LoRA 与模型目录可以稍后添加。已有配置会保留，只有点击保存才会更新。

仅共享指定的任务文件夹

  1. 打开下方文件夹，返回上一级，右键该文件夹 → 属性 → 共享 → 高级共享。
  2. 勾选共享，记下共享名称；在共享权限与「安全」页仅给用于连接的账号读取与写入权限。
  3. 保留密码保护共享。只在可信的专用网络启用文件共享；不要关闭防火墙或为 Everyone 开放整个磁盘。

在 Mac 工作台的「设备连接 → 开始配对引导」粘贴地址。系统登录使用 Windows 账号密码，不是 PIN。

确认服务真正就绪

    引导不会自动修改共享、账号或防火墙。
