# 可选本地模型

打开「设备连接 → 管理可选模型」，或从创作台 WD14 区进入安装界面。没有安装模型也能管理项目、调用外部 API 和使用 ComfyUI。仅打开界面不会下载任何文件。

| 模型 | 用途 | 完整下载大小 |
| --- | --- | --- |
| WD14 / wd-swinv2-tagger-v3 | 二次元和插画 Booru 标签草稿 | 约 468 MB |
| idolsankaku-swinv2-tagger-v1 | 真人与摄影标签草稿，在数据集工作区选择 | 约 420 MB |
| CLIP / clip-vit-base-patch32 | 相似图检索；安装后还需建立图片索引 | 约 352 MB |

## 安装到哪里

弹窗显示运行 WebUI 服务的设备及绝对模型目录。Windows 单机模式装在 Windows；Mac 运行的 WebUI 服务装在 Mac。浏览器所在设备不决定安装位置，此入口不会给远程 Worker 安装模型。

默认目录是用户文档中 `Soda Prompt Hub/models`，可沿用已有 `PROMPT_HUB_MODELS_ROOT` 设置。不是 ComfyUI 的 checkpoint 或 LoRA 目录。

## 下载与校验

点击某张卡片的「下载并安装」后，后台任务显示排队、下载字节数、百分比、SHA-256 校验及本机推理自检。完成后显示「可用」。不自动打标、不覆盖人工说明、不切换已有自定义视觉模型。

- 下载地址仅允许固定的 Hugging Face 模型版本和受信任的 HTTPS 重定向，不接受用户任意 URL。
- 可取消、续传与重试；关闭弹窗或刷新页面不等于取消下载。
- 网络读取或 CPU 自检期间，取消可能需要等待当前操作结束。
- 模型自检使用合成输入，不读取或上传用户图片，不调用付费 API。当前打标使用 CPU，不承诺 CUDA 加速。
- 下载需要磁盘空间与可访问 Hugging Face 的网络。相同模型的重复安装请求复用活动任务。

## 已有模型与手动安装

展开卡片的「来源、文件与安装位置」，从固定版本下载文件，放入所示目录，再点击校验。WD14 和真人模型都需要 `model.onnx`、`selected_tags.csv`；CLIP 需要 `vision_model.onnx`。

发现已有文件时不会静默覆盖。与推荐版本不匹配的文件需要用户先备份、移走或继续沿用原来的自定义模型接入方式。安装器生成自己的校验记录，文件变化后需要重新校验。

语言模型和看图模型不属于这三个固定安装项，可从弹窗进入「模型接入」连接 LM Studio、Ollama 或外部 API。下载来源页面同时提供模型许可信息；本功能不构成对所有再分发或商业用途的许可保证。
