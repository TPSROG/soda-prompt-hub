# Prompt Hub 1.1.1 pre1 手动验收

本清单用于 `2026-09-14 pre1` 预发布候选。程序内部版本为 `1.1.1`，GitHub Release 若后续上传必须标记为
Pre-release；未完成本清单前不得设为 Latest。安装器暂未做 Windows Authenticode 或 Apple Developer ID 签名。

## 先核对包

| 使用方式 | 应安装文件 | 不应同时打开 |
| --- | --- | --- |
| Mac 管理 Windows | Mac 安装 `Soda-Prompt-Hub-1.1.1-macOS-arm64.dmg`；Windows 安装 `Soda-Compute-Worker-1.1.1-Setup.exe` | Windows 单机版 Desktop |
| Windows 单机 | Windows 安装 `Soda-Prompt-Hub-Desktop-1.1.1-Setup.exe` | 独立 Compute Worker |

1. 用包内 `SHA256SUMS.txt` 核对附件。
2. 停止旧启动器和服务，再覆盖安装；不要删除个人资料目录。
3. 安装后首页、启动器和诊断信息均应显示 `1.1.1`。

## A. Mac 管理 Windows

1. Windows 只打开 `Soda Compute Worker`，确认 Worker 与 ComfyUI 自检通过。
2. Mac 打开 `Soda Prompt Hub`，进入“设备连接”。
3. 在线卡片应在数秒内明确显示可计算、心跳时间和 ComfyUI 状态；关闭 Windows Worker 后应变为离线，重新打开后恢复。
4. 创建一个测试项目，向 Windows 提交一次低成本工作流；任务应依次显示等待、处理中、完成，结果能回到项目。
5. 取消一个尚未完成的测试任务；历史记录应显示“已取消”、取消时间和取消原因，不应伪装成普通失败。
6. 从 Mac 菜单栏执行“退出并停止服务”，确认 8765 服务停止；重新打开后项目与配置仍在。

## B. Windows 单机

1. 只打开 `Soda Prompt Hub`，确认启动器自动启动 Core 和本机 Worker，WebUI 能直接进入业务页面。
2. 关闭窗口后从托盘恢复；“退出启动器”保留服务，“退出并停止本机服务”停止当前启动器持有的服务。
3. 在“设备连接”确认页面说明为 Windows 单机模式，不要求 Mac 配对或 SMB。
4. 创建测试项目并跑一个低成本 ComfyUI 工作流，确认任务状态、结果回传和项目旅程一致。

## C. 本轮修复专项

### 完整备份

1. 进入“资料管理”找到“完整备份与自动校验”。
2. 核对估算大小、可用空间和默认目标目录，点击开始。
3. 页面应持续显示进度；完成后明确显示“校验通过”和备份绝对路径。
4. 保持 Prompt Hub 运行时执行一次备份，不能再出现 SQLite 文件被占用或 rename 失败。
5. 在一个小测试库上取消备份，状态应为已取消；不要用正式大资料库做破坏性恢复测试。

### 数据集文件夹

1. 在数据集工作区生成一个资料集副本。
2. 点击“打开所在文件夹”。Windows 应由 Explorer 定位目标；Mac 应由 Finder 定位目标。
3. 目标消失或文件管理器启动失败时，页面应显示可读错误，不应只弹出 `请求失败：500`。

### Krea 2 中文翻译

1. 打开一张有视觉模型英文草稿的图片，“Krea 2 中文翻译（仅供审核）”应翻译这段草稿。
2. 打开一张没有视觉草稿、但已有正式 Krea 2 英文说明的图片，翻译仍可执行。
3. 修改英文来源后，旧译文应失效并提示重新翻译。
4. 生成资料集副本后确认中文译文没有写入 Anima 标签或 Krea 2 英文交付文件。

### Windows 出图来源与清理

1. 进入“Windows 出图”，设置一个存在的 ComfyUI output 目录，并勾选“设为常用结果目录”。
2. 重新打开页面后目录仍应自动填入；扫描时应显示进度。
3. 新结果卡片应显示来源类型、来源目录、导入时间和批次，并能按来源筛选。
4. 选择一个未关联项目的测试结果执行“移出结果库”：源 output 图片必须保留，管理副本进入 Prompt Hub 内部回收区。
5. 已关联项目的结果应拒绝移出。旧记录允许只显示“历史导入”，不能凭空显示伪造路径。

## D. 建议由用户执行的高成本项目

- 使用实际外部 API 执行一次 AI 补全和一次 Krea 2 改写，核对额度、超时和错误提示。
- 使用常用正式工作流完成一次真实出图，核对 checkpoint、LoRA、seed、Prompt 和 ComfyUI metadata。
- 对真实大 output 目录执行一次完整扫描，观察性能、取消与续跑。
- 对正式资料库执行一次完整备份，并人工抽查备份中的数据库、图片和来源资料。
- 如需训练，再生成 Anima/Krea 2 双格式资料副本并交给训练工具；安装包本身不包含模型权重或训练环境。
